# 国产定制 ROM 进程保活与自启动配置指引 (ROM Keep-Alive Guide)

> **适用场景**：Voice Kiosk 作为家庭智能语音屏与床头/桌面常驻设备运行时，保障**精确闹钟准时唤醒响铃**、**倒计时后台稳定运行**与**语音唤醒服务常驻不被杀**。  
> **权限声明原则**：严格仅使用 Phase 2 已声明的标准权限（`SCHEDULE_EXACT_ALARM`、`USE_EXACT_ALARM`、`WAKE_LOCK`、`RECEIVE_BOOT_COMPLETED` 与 `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`），严禁新增任何私有或越权权限。

---

## 1. 为什么需要保活配置

Android 系统（特别是国内主流厂商定制 ROM）具备激进的后台资源回收与省电机制（如深度休眠 Doze 模式、智能冻结、纯净模式与链式杀后台）。

虽然 Voice Kiosk 在架构层做了多重加固：
1. **硬件 RTC 唤醒**：钟点闹钟使用 `AlarmManager.setExactAndAllowWhileIdle(RTC_WAKEUP)`，由 Linux 内核 RTC 硬件定时器直接唤醒 CPU；
2. **前台麦克风服务常驻**：`VoiceKioskService` 配置为前台服务并常驻系统通知栏；
3. **开机自启恢复**：`BootReceiver` 监听系统广播并在设备重启时全量重新注册所有未触发闹钟。

但在部分品牌手机上，如果未授予“允许自启动”或未将应用加入“电池优化白名单”，系统在熄屏 10~30 分钟后可能会：
- 强行切断后台网络连接（导致看板 WebSocket 断连与增量同步停滞）；
- 拦截广播启动（导致重启后无法唤醒应用注册闹钟）；
- 拦截悬浮窗或锁屏亮屏弹窗（导致闹钟到达时刻虽在后台发出了广播，但无法点亮屏幕弹出交互界面）。

## 2. 主流国产定制 ROM 一次性配置步骤

设备初次安装或重装 Voice Kiosk 后，请按照对应机型完成以下一次性设置：

### 2.1 华为 / 荣耀 (HarmonyOS / EMUI / MagicOS)

1. **关闭自动管理，开启自启动与后台活动**：
   - 打开“手机管家” -> 点击“应用启动管理”；
   - 在应用列表中找到 **Voice Kiosk**；
   - 将开关由“自动管理”切换为**手动管理**；
   - 在弹出的三个选项中全部勾选开启：
     - [x] **允许自启动**
     - [x] **允许关联启动**
     - [x] **允许后台活动**
2. **忽略电池优化**：
   - 进入系统“设置” -> “应用和服务” -> “应用管理” -> 点击右上角四个点 -> “特殊访问权限” -> “电池优化”；
   - 顶部下拉选择“所有应用”；
   - 找到 **Voice Kiosk**，设置为 **“不允许”**（即忽略电池优化，不限制耗电）。
3. **允许悬浮窗与锁屏显示**：
   - 进入系统“设置” -> “应用和服务” -> “应用管理” -> **Voice Kiosk** -> “权限”；
   - 允许“悬浮窗”与“在锁屏上显示”权限。
4. **多任务卡片加锁**：
   - 从屏幕底部上滑悬停进入多任务后台；
   - 找到 Voice Kiosk 卡片，向下滑动卡片（或点击卡片右上角锁图标）进行锁定。

---

### 2.2 小米 / 红米 (HyperOS / MIUI)

1. **开启自启动权限**：
   - 打开“手机管家” -> 点击“应用管理” -> “权限” -> **“自启动管理”**；
   - 找到 **Voice Kiosk** 并开启开关。
2. **关闭省电限制（无限制）**：
   - 进入“设置” -> “应用设置” -> “应用管理” -> 搜索并进入 **Voice Kiosk**；
   - 点击“省电策略” -> 选择 **“无限制”**（HyperOS/MIUI 默认是“智能省电”，会导致熄屏杀后台）。
3. **允许后台弹出与锁屏显示**：
   - 在 Voice Kiosk 应用信息页 -> 点击“权限管理”；
   - 找到并开启 **“显示在锁屏上”**、**“后台弹出界面”** 与 **“常驻通知”**。
4. **精确闹钟权限确认 (Android 12+)**：
   - 在应用信息页 -> 检查“闹钟和提醒”权限已开启。
5. **多任务卡片加锁**：
   - 进入多任务后台界面 -> 长按 Voice Kiosk 卡片 -> 点击小锁图标锁定。

---

### 2.3 OPPO / 一加 / 真我 (ColorOS / OxygenOS / Realme UI)

1. **允许应用自启动与关联启动**：
   - 进入“设置” -> “应用” -> “应用自启动”；
   - 开启 **Voice Kiosk** 的自启动开关，并进入详情开启“允许关联启动”。
2. **电池耗电管理无限制**：
   - 进入“设置” -> “电池” -> “更多设置” -> “耗电异常优化”；
   - 将 Voice Kiosk 设为 **“不优化”**；
   - 进入“设置” -> “应用” -> “应用管理” -> **Voice Kiosk** -> “耗电管理”；
   - 开启 **“允许完全后台行为”** 与 **“允许前台活动”**。
3. **悬浮窗与锁屏通知**：
   - 进入“设置” -> “应用” -> “权限管理” -> “悬浮窗”；
   - 开启 Voice Kiosk 的悬浮窗权限与锁屏通知。
4. **多任务卡片锁定**：
   - 调出多任务界面 -> 点击 Voice Kiosk 卡片右上角三个点 -> 选择 **“锁定”**。

---

### 2.4 vivo / iQOO (OriginOS / FuntouchOS)

1. **开启自启动**：
   - 打开“i管家” -> “应用管理” -> “权限管理” -> “自启动”；
   - 开启 **Voice Kiosk** 自启动允许。
2. **后台高耗电白名单**：
   - 进入系统“设置” -> “电池” -> “后台高耗电”；
   - 找到 **Voice Kiosk** 并开启开关（允许后台持续高耗电运行）。
3. **悬浮窗与桌面通知**：
   - 进入“设置” -> “应用与权限” -> “权限管理” -> 开启 Voice Kiosk 的“悬浮窗”与“锁屏显示”。
4. **后台卡片加锁**：
   - 上滑进入后台多任务，向下滑动 Voice Kiosk 卡片完成锁定。

---

### 2.5 原生 / 国际版 Android (AOSP / Pixel / Motorola)

1. **精确闹钟权限 (Alarms & reminders)**：
   - 进入“Settings” -> “Apps” -> “Special app access” -> “Alarms & reminders”；
   - 找到 **Voice Kiosk** -> 切换为“Allowed”。
2. **电池无限制 (Unrestricted battery)**：
   - 进入“Settings” -> “Apps” -> **Voice Kiosk** -> “Battery”；
   - 选择 **“Unrestricted”**。

## 3. 应用内置自动检测与双重提醒机制 (In-App Checks)

应用在端侧启动及设定闹钟时内置了主动探测与防御逻辑：

### 3.1 权限探测清单
- **精确闹钟权限检测 (`AlarmManager.canScheduleExactAlarms`)**：
  在 Android 12+ (API 31+) 设备上，主动判断系统是否赋予了精确排期权限。
- **忽略电池优化检测 (`PowerManager.isIgnoringBatteryOptimizations`)**：
  在 Android 6.0+ (API 23+) 设备上，检测应用包名是否处于系统电池优化白名单内。

### 3.2 界面与语音双重提醒
当检测到任一关键保活权限缺失时：
1. **屏幕可视提示 (On-Screen Toast / Prompt)**：
   应用首页立即弹出显著提示：
   > “请为 Voice Kiosk 开启精确闹钟和忽略电池优化权限，以保证闹钟准时响铃与后台稳定运行。”
2. **语音播报提示 (Spoken Feedback)**：
   - 若用户通过语音设置闹钟但缺少精确闹钟权限，系统立即口语化回话：
     > “闹钟没定上，请先在设置里打开精确闹钟权限，再说一次就行。”
   - 并自动唤起系统设置页面直接引导授权，避免盲目失败。
3. **一键引导跳转**：
   应用通过系统标准的 `Settings.ACTION_REQUEST_SCHEDULE_EXACT_ALARM` 和 `Settings.ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` Intent 引导用户直达设置项，无须在多层级系统菜单中搜索。
